# Fsd3-skinlab1.0
FSD3 Skin Studio is a PC tool for building and previewing FreeStyleDash 3 skins. It opens folders and .xzp packs, including retail .xur-only skins, with full rendering for .xui source and a control breakdown for compiled scenes, plus one-click decompile, scene editing, timeline scrubbing, packing, and validation. Made by StoicDemon.
